## 2. 逐步计算过程文档

在 `docs/formulas.md` 中为每种模型类型添加完整的逐步计算示例。

### 2.1 Dense 模型示例

```
输入：LLaMA-2 7B, FP16, seq_len=2048, concurrency=1

步骤1: 架构推断
  P = 7×10⁹, L = (7×10⁹ / (12×128²))^(1/3) ≈ 32
  hidden_dim = 128 × 32 = 4096, num_heads = 32

步骤2: 权重显存
  7×10⁹ × 2 bytes = 14 GB

步骤3: KV Cache
  2 × 32 × 4096 × 2048 × 1 × 2 = 1.07 GB

步骤4: 激活值
  1 × 2048 × 4096 × 32 × 2 × 2 = 1.07 GB

步骤5: 基础显存
  14 + 1.07 + 1.07 = 16.14 GB

步骤6: 框架开销
  碎片化 = 16.14 × 0.10 = 1.61 GB
  运行时 = 0.8 GB

步骤7: 总显存
  16.14 + 1.61 + 0.8 = 18.55 GB

步骤8: FLOPs
  Prefill = 2×7×10⁹×1024 = 1.43×10¹³
  Decode = 2×7×10⁹×1024 = 1.43×10¹³
  总计 = 2.86×10¹³

步骤9: 吞吐量
  计算受限 = 312×10¹² / (2×7×10⁹) = 22.3 tokens/s
  带宽受限 = 2039×10⁹ / (7×10⁹×2 + 2×32×4096×2) = 68.5 tokens/s
  实际 = min(22.3, 68.5) = 22.3 tokens/s（计算受限）
```
